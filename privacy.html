Privacy Policy – ytauto

Last updated: 28 October 2026

What ytauto is

ytauto is a personal script used only by its owner to upload videos to the owner's own YouTube channel. It has no other users.

Data accessed

With the owner's permission, ytauto uses the YouTube Data API to upload videos, set thumbnails and read basic channel information. It does not access any other user's data.

Storage and sharing

The access token is stored only on the owner's private server and computer. No data is sold, shared with third parties or used for advertising.

Revoking access

Access can be removed at any time at https://myaccount.google.com/permissions.

Google policies

ytauto uses YouTube API Services and follows the YouTube Terms of Service, the Google Privacy Policy and the Google API Services User Data Policy.
